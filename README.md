# треня темы

Список упражнений с гантелями и длинной гантелью на все группы мышц: анимация движения с подсветкой работающих мышц, техника по шагам и частые ошибки.

Есть карта тела, избранное, таймер подхода и отдыха, готовые программы с пошаговым проигрывателем, разминка и заминка. После первого открытия сайт работает без интернета.

Сайт статический: только HTML, CSS, JS и SVG-картинки, без внешних библиотек и запросов.

## Как выложить на GitHub Pages

1. Загрузи в корень репозитория все файлы из этой папки (включая скрытый `.nojekyll`).
2. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. Включи «Enforce HTTPS».
3. Сайт: `https://<логин>.github.io/<репозиторий>/`

При обновлении сайт сам покажет «Есть новая версия сайта» — нажми «Обновить».

## Безопасность

- Content-Security-Policy: скрипты, стили, картинки и офлайн-воркер только с этого же сайта; инлайн-скрипты, eval, формы, плагины и `<base>` запрещены.
- Trusted Types: вставка HTML через `innerHTML` запрещена браузером; разрешён единственный адрес `./sw.js` для офлайн-режима.
- Весь интерфейс строится через `textContent` и `createElement`; поиск и адресная строка никогда не попадают в HTML.
- Якорь `#id` принимается только для известного упражнения; избранное из памяти телефона проверяется по списку упражнений.
- Офлайн-воркер обрабатывает только запросы к этому же сайту.
- Защита от встраивания во фрейм, `no-referrer`, никаких внешних ресурсов, трекеров и cookies. Избранное хранится только на устройстве.
