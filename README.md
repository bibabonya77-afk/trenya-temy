# треня темы

Список упражнений с гантелями и длинной гантелью на все группы мышц: анимация движения с подсветкой работающих мышц, техника по шагам и частые ошибки.

Сайт статический: только HTML, CSS, JS и SVG-картинки, без внешних библиотек и запросов.

## Как выложить на GitHub Pages

1. Создай репозиторий и загрузи в корень все файлы из этой папки (включая скрытый `.nojekyll`).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. На той же странице включи «Enforce HTTPS».
4. Через минуту сайт будет по адресу `https://<логин>.github.io/<репозиторий>/`.

## Безопасность

- Content-Security-Policy: скрипты, стили и картинки только с этого же сайта; инлайн-скрипты, eval, формы, плагины и `<base>` запрещены.
- Trusted Types: запрещены опасные вставки HTML через `innerHTML` и подобные.
- Весь DOM строится через `textContent` и `createElement`, текст из поиска и адресной строки никогда не вставляется как HTML.
- Якорь в адресе (`#id`) принимается только если совпадает с известным упражнением.
- Защита от встраивания во фрейм (кликджекинг) скриптом, потому что GitHub Pages не позволяет задать заголовок.
- `Referrer-Policy: no-referrer`, никаких внешних ресурсов, трекеров и cookies.
